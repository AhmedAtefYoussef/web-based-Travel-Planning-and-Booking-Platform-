# Traceability matrix (Milestone 1)

Requirement IDs and text come from `docs/requirements/reqs.json` (the workbook); Jira keys and owners from `docs/requirements/jira-map.json`. Members add their rows through their PRs. Each requirement row lists the proof tests and the exact command that was run from `backend/`.

## How status is decided

- PASS: every listed test was run with `npx jest ... -t "<names>"` (the command in the row), jest reported all of them as passed, and no listed name was missing from the run.
- FAIL: a test failed. MISSING: no test exists.
- Evidence run: 2026-11-03 on branch `docs/M1-traceability` from `origin/develop` at `439118e` (Stripe mocked, MongoDB in-memory replica set). `-t` takes a regex, so literal `(` `)` `+` in test names are escaped with a backslash.
- Whole suites: `npm test` (unit) and `npm run test:e2e` (e2e).
